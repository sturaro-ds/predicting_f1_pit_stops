## 1. F1 Pit Stop Prediction: A Comparative AutoML Study Across Data Strategies

This study builds an end-to-end machine learning pipeline to predict the probability of a Formula 1 pit stop. It starts with exploratory data analysis and data preparation, followed by feature engineering to enhance predictive signals. Multiple dataset variants are created to compare different strategies, including models trained with and without the driver feature, as well as with engineered features. AutoML is applied to each scenario to automatically select and optimize models. Finally, performance is evaluated using metrics such as ROC AUC, enabling a comparative analysis to identify the best trade-off between accuracy and model simplicity.
